这里与左侧不是一一对应的：左边是核心机制，这里是完整入口。没有 L0 element 的 Topic 也照样能进入。

  • T-01 三级递进语义
    Receipt、Availability、Consumption 是三个可以同时为真、但不能互相替代的语义层级 —— 上下文到了不等于可用，可用不等于被消费；被消费的是教学语义，不是实现控制对象。
    elements
    出处（无出处）· L2 blocks: O-02, O-07, O-08, O-09
  • T-02 生成链路与消费点
    消费点是 outline generation：Frozen Context 派生出的 projection 必须成为 outline 生成的真实输入，而不是被附加在 Prompt 里；scene 继承的是 context-shaped outline。
    elements
    出处（无出处）· L2 blocks: O-04, O-04b, O-04c
  • T-03 消费的证据与判定
    判定消费的最低证据是「某一次 Outline Generation Attempt 实际使用了 generation-facing projection」；函数调用、Prompt 字符串、成功返回都不能升级为 Consumption。
    elements
    出处（无出处）· L2 blocks: O-10, O-10b, O-16, O-14
  • T-04 两条链的边界与状态组合
    Consumption 管「这次生成用了什么」，Output Alignment 管「生成出来体现了什么」；两链在 outline revision 处衔接，五种状态组合各有产品解释。
    elements
    出处（无出处）· L2 blocks: O-05, O-06, O-11b, O-13
  • T-05 语义边界与非主张
    消费不要求盲目服从，也不要求输出明显不同；本篇不采用第四级 Context Influence，也不承诺某个输出变化严格由上下文导致。
