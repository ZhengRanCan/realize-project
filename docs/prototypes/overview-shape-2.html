O-14b 明确不决定的 9 项 / 明确不承诺的 5 项 Source: §15
§15 是全文的"非主张"清单，之前完全没进 Overview。 这类内容用 ✗ 清单承载最直接：它们不是"待办"，而是已经被排除的承诺。
本文不决定（9 项）
  • 最终 Receipt / Availability / Consumption 的 JSON 字段
  • Context Consumption evidence 的具体结构
  • 生成器如何消费上下文（Prompt / planner / 模板 / 混合）
  • 是否需要记录生成设计决策
  • 由 OpenMAIC 内部判断，还是产生受控跨边界结果
  • 未消费或不可用时：阻止生成 / 回退普通课堂 / 允许草稿
  • 与未来实验性因果分析的关系
本文不承诺（5 项）
  • DeepTutor 的语义一定正确
  • 模型内部推理被理解或被验证
  • Prompt 中包含上下文就一定发生 Consumption
  • 最终输出一定发生了由 DeepTutor 引起的变化
  • Output Alignment 可以由 Consumption 单独证明
