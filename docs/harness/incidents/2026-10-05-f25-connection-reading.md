# F25 连接解释与图的阅读距离

Date: 2026-10-05. 用户实际试读反馈，尚未实施修正。

## 实际反馈

用户认为整体展示尚可，认可“查看连接的含义 · 4条”的入口，但框架图较大，连接目录和选择详情在图下方，阅读时需要反复滚动，难以同时对照连接和解释。

截图显示长图占据主要高度，连接目录在图外下方。当前 renderer 的 guide-edge-list 和 l0-focus-slot 均在 l0-reading 图后；图独立滚动，主内容仍需要向下滚动到目录或解释。

## 修正目标

让读者在保留图的当前滚动位置时，直接阅读选中连接/节点的含义和依据，连续切换连接无需往返长图底部。继续保留完整连接集合、Topic 入口、键盘与 Back/Source 恢复、窄窗口以及只读 Preview。

本次属于 F25 既有展示与现场恢复的局部调整，不新增解释协议或 feature。用户已确认固定含义/主题面板和窄窗口底部收起的短设计，开始在 F25 内修正。用户“整体看上去还行”是部分正向反馈，不替代合同要求的实际复述与 Topic 选择验收，F25 不据此标 passing。

真实原生键盘测试发现：从 Topic 成员按钮选择对象后自动切到含义，原焦点按钮被隐藏，焦点落到 body。切换时把这类被隐藏的面板内焦点转到可见的当前标签；图上的选择者焦点仍保留。补回归后再验证。

独立审查发现 canonical Element 返回时，面板状态先恢复，随后 revealElement 又展开含义而覆盖状态。调整为 canonical 可见性恢复后再恢复面板状态，补真实 Element→Topic/Explore→Back 的标签/收起/焦点断言。

补强返回测试发现非活动含义标签的滚动位置在 DOM 隐藏/重建时丢失。面板 frame 显式保存两个标签的滚动值，切换和返回恢复；不依赖隐藏元素的 scrollTop 读写。


## 技术修正结论

面板已接入桌面、窄窗口、独立 Map/Review及便携 Preview；隐藏焦点、canonical 恢复顺序和非活动标签滚动的缺陷已修正，原生回归和独立复查通过。正式证据在 F25 reading-panel-verification.md；新版体验待用户实际确认。
